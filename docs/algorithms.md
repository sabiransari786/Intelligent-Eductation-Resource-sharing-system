# Algorithms

| Algorithm | Input/output | Purpose | Complexity |
|---|---|---|---|
| BST | keys → traversals/search | ordered educational-title demonstration | O(h) search/insert |
| Inorder, preorder, postorder, level-order | tree → key sequence | compare exploration strategies | O(n) |
| BFS / DFS | graph + start → visited IDs | related-resource exploration | O(V+E) |
| Dijkstra | weighted graph + endpoints → path/cost | minimum transition cost, not an objectively best learning sequence | O(V²+E) |
| 0/1 Knapsack | items + minute budget → selected items/value | study planning with each resource once | O(nC) |
| Red-Black Tree | keys → ordered index/invariant report | balanced-tree teaching demonstration | insertion/search demonstration |
| Kruskal | weighted edges → forest/MST report | optional graph optimization demonstration | O(E log E) |

Graph edges are undirected by default, have non-negative integer weights, and connect sample subject/topic/resource nodes. Invalid nodes and negative weights return API errors. Empty trees, empty candidate lists, zero capacity, unreachable destinations, and invalid input are handled.
